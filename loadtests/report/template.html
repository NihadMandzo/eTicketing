Method

How these numbers were made

  1. An isolated copy of the platform in Docker (own database, Redis and broker), reached only through the public Gateway, exactly like the web and mobile apps. Payments on the Mock provider; email and PDF services off so no real email is sent.
  2. k6 2.3.0 inside the same Docker network. In the mixed scenario every user browses with 1–3 s think time between clicks; every tenth registers and buys a ticket through hold → payment intent → purchase.
  3. Percentiles on this page are computed from every individual request (k6 CSV output), in 5-second buckets for the time series. CPU comes from docker stats every 10 s, the event backlog from the outbox tables every 10 s.
  4. One 16-core laptop ran the platform and the load generator together, so above a few thousand users they compete for the same CPU. Production numbers will differ; the scripts are ready to run against a staging deployment from a separate machine.
